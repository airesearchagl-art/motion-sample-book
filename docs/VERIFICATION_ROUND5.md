## 3. 記録の形

`src/recipe-checks.ts` の `recipeChecks` に、`'V22'`〜`'V33'`、`'21'`〜`'30'` のキーで追加する。形はこれまでと同じ（`status`・`checkedWith`・`date`・`note`・`fix`・`d5`）。

- `fix` は、そのまま `recipes.ts` の該当欄を置き換えられる1文にする（今の書き方に合わせ、ほかの道具の部分も含めた欄全体）。
- `cg` は、D5 で確かめた部分を `checkedWith`・`d5` に、SketchUp 部分を `status`（device／mismatch）に、Lumion／Twinmotion の扱いを `note` に書く。
- 動画を書き出して動きまで見たか、名称だけかを `note` に残す。動きを見ていないものは `note` に「見た目は未確認：…」と書く（画面に「D5での動きは未確認」と出る）。
