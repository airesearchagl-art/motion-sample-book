## 2. 作り方の目安

- **場面**：1つの D5 プロジェクトにまとめてよい。地面、簡単な建物（箱でよい）、手前に木（Assets > Model > Nature）、水盤、道路と車のパスを置く。室内（E05）は窓のある箱を別の視点で。
- **書き出し**：見本ごとに、カメラを止めた短い動画（5〜8秒、720p程度で十分）を書き出す。比べるために、設定を変えた2本（例：Wind オフ／オン、Flow Velocity 小／大）を書き出すと分かりやすい。
- **動きの確かめ方**：書き出した動画から、1秒ごとの静止画を数枚切り出して並べ、違いがあるか（揺れ・波・雪・車の位置・霧の濃さ）を見る。ffmpeg が使えればそれで、なければ動画を再生して時間をずらした画面を撮る。
- **V21**：SketchUp（9876、mm）で、構造（柱・梁）・設備（ダクト・配管）・仕上げ（外装）を別々の .skp に保存する（第3弾の `verify_sketchup_v21.skp` をタグごとに分けて書き出してよい）。D5 で3つを読み込み、Inspector の Location を揃えて、表示を切り替えた画像を3枚書き出す。

## 3. 記録の形

`src/recipe-checks.ts` の各見本の `cg` を更新する。

- 動いた：`status` は `device` のまま。`note` の先頭に「見た目も動画で確認（YYYY-MM-DD）：…」と、何が動いたかを1文で足す。
- 記載と違った（動かない、別の設定が必要など）：`status` を `mismatch` にし、`fix` に `recipes.ts` の cg 欄全体をそのまま置き換えられる文を書く。`d5` も実際の手順に直す。
- 試せなかった：`note` に「見た目は未確認：理由」を残す。
- `date` は今回の日付にする。
