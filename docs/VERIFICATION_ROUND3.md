### 環境（E）の見本の前提

建物とカメラは止めたまま、風・水・人・天気・光・季節だけを動かす見本。1枚のパースやCGの静止画に空気感を足す使い方を想定している。確認でも「建物とカメラを動かさずに、その環境の動きだけを作れるか」を見る。

## 3. 記録の形

`src/recipe-checks.ts` の `recipeChecks` に、`'E01'`〜`'E10'`、`'V21'` のキーで追加する。形はこれまでと同じ（`status`・`checkedWith`・`date`・`note`・`fix`・`d5`）。

- `fix` は、そのまま `recipes.ts` の該当欄を置き換えられる1文にする（今の記載の書き方に合わせ、ほかの道具の部分も含めた欄全体）。
- `cg` は、D5 で確かめた部分を `checkedWith`・`d5` に、Lumion／Twinmotion／Navisworks の扱いを `note` に書く。
- V21 の `cg` は SketchUp 部分を `status`（device／mismatch）に、D5 を `d5` に書く。
- 再生で動きを確かめたか、名称だけかを `note` に残す。

## 4. 報告書

`docs/RECIPE_VERIFICATION.md` に「第3弾（環境の動き・V21）」の節を足す。
