# モーション見本帳

操作の動きが一目でわかる動き見本帳。

> A motion sample book for UI interactions.

名前を思い出せない動きを、実際に触りながら探すための小さな図鑑です。UIモーション、動画・カメラ、文字の3つの見本帳に、合計25種類を収録しています。各見本には「向いている場面」と「避けたい場面」を添えています。

## 収録している動き

### UIモーション（10）

1. ふわっと浮く
2. 大きくなる
3. 押し込まれる
4. ぷるっと弾む
5. 左右に揺れる
6. 少し傾く
7. 下線が伸びる
8. 背景色が広がる
9. 光が横切る
10. 波紋が広がる

### 動画・カメラ（10）

- つなぎ：カット、フェード、ワイプ
- カメラ：ズーム、パン、チルト、ドリーイン、オービット、トラック、ラックフォーカス

### 文字（5）

フェードイン、タイプ表示、文字送り、分解／集合、マスク表示
