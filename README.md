# モーション見本帳

操作の動きが一目でわかる動き見本帳。

> A motion sample book for UI interactions.

名前を思い出せない動きを、実際に触りながら探すための小さな図鑑です。UIモーション、動画・カメラ、文字の3つの見本帳に、合計50種類を収録しています（UI 20／動画・カメラ 20／文字 10）。各見本には「向いている場面」と「避けたい場面」を添えています。

## 収録している動き

### UIモーション（20）

1. ふわっと浮く
2. 大きくなる
3. 押し込まれる
4. ぷるっと弾む
5. 左右に揺れる
6. 少し傾く
7. 下線が伸びる
8. 背景色が広がる
9. 光が横切る
10. 波紋が広がる
11. 前後比較スライダー
12. 画像のクリップ表示
13. 視差（パララックス）
14. ゆっくり拡大（ケン・バーンズ）
15. 詳細へ拡大
16. カードの裏返し
17. カーテン遷移
18. グリッドの並び替え
19. 横スクロール
20. ピンが落ちる

### 動画・カメラ（20）

- つなぎ：カット、フェード、ワイプ
- カメラ：ズーム、パン、チルト、ドリーイン、オービット、トラック、ラックフォーカス、クレーンアップ、プルバック、フライスルー、ミニチュア（ティルトシフト）
- 建築CG：断面カット、デイ・トゥ・ナイト、日影の移動、平面図から立体へ、分解／組み上げ
- つなぎ（追加）：線画からレンダーへ

### 文字（10）

フェードイン、タイプ表示、文字送り、分解／集合、マスク表示、字間が開く、線で描かれる文字、数字のカウントアップ、寸法線と一緒に表示、引き出し線の注記

## できること

- 感覚語や用途で、3つの見本帳をまとめて検索する
- 2つの見本を横に並べて、同時に再生して比べる
- 速度・強さ・向きを変えて再生する
- 気に入った見本を保存し、用途別のコレクションに分ける（保存先はこの端末のブラウザ内だけ）
- 各見本の再現情報（CSS、Premiere Pro／After Effects、PowerPoint、建築CG、生成AI向けの指示文）をコピーする

## 使い方ページ

操作方法は、サイト右上の「使い方」（`/guide.html`）にまとめています。

- 内容は `src/guide.ts` の `sections`（項目ごとの説明）と `changelog`（更新履歴）で管理しています。
- 見本の件数や、「強さ」「向き」が効く見本の一覧は、見本帳と共通の `src/data.ts` から自動で反映されます。
- 冒頭の「画面マップ」の画像と番号の位置は、画面の構成を変えたら `npm run guide:capture` で撮り直します（Playwrightが必要。手順は `scripts/capture-guide-map.cjs` の冒頭）。番号の説明文は `src/guide.ts` の `mapItems` にあります。
- 機能を追加・変更したPRでは、使い方ページも同じPRで更新します（PRテンプレートで確認）。

## 見本を追加するとき

1. `src/data.ts` に見本の基本情報（名前、説明、向いている場面、避けたい場面、感覚語）を足す
2. `src/recipes.ts` に同じ番号で再現情報を足す（開発サーバーでは、足りないと警告が出ます）
3. プレビューの画面とCSSを `src/main.ts`・`src/style.css` に足す
4. 「強さ」「向き」が効く場合は `src/data.ts` の一覧に番号を足す（使い方ページにも自動で反映）
