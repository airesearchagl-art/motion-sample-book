# モーション見本帳

操作の動きが一目でわかる動き見本帳。

> A motion sample book for UI interactions.

名前を思い出せない動きを、実際に触りながら探すための小さな図鑑です。UIモーション、動画・カメラ、文字、環境の4つの見本帳に、合計61種類を収録しています（UI 20／動画・カメラ 21／文字 10／環境 10）。各見本には「向いている場面」と「避けたい場面」を添えています。

## 収録している動き

### UIモーション（20）

1. ふわっと浮く
2. 大きくなる
3. 押し込まれる
4. ぷるっと弾む
5. 左右に揺れる
6. 少し傾く
7. 下線が伸びる
8. 背景色が広がる
9. 光が横切る
10. 波紋が広がる
11. 前後比較スライダー
12. 画像のクリップ表示
13. 視差（パララックス）
14. ゆっくり拡大（ケン・バーンズ）
15. 詳細へ拡大
16. カードの裏返し
17. カーテン遷移
18. グリッドの並び替え
19. 横スクロール
20. ピンが落ちる

### 動画・カメラ（21）

- つなぎ：カット、フェード、ワイプ
- カメラ：ズーム、パン、チルト、ドリーイン、オービット、トラック、ラックフォーカス、クレーンアップ、プルバック、フライスルー、ミニチュア（ティルトシフト）
- 建築CG：断面カット、デイ・トゥ・ナイト、日影の移動、平面図から立体へ、分解／組み上げ、構造・設備・仕上げを重ねる
- つなぎ（追加）：線画からレンダーへ

### 文字（10）

フェードイン、タイプ表示、文字送り、分解／集合、マスク表示、字間が開く、線で描かれる文字、数字のカウントアップ、寸法線と一緒に表示、引き出し線の注記

### 環境（10）

建物とカメラは止めたまま、環境だけを動かす見本：植栽の揺れ、水面のゆらぎ、人の往来、雲の流れ、木漏れ日、雨、雪、車の光跡、霧・もや、季節の移ろい

## できること

- 建築プレゼンの目的（敷地と全体像、空間の体験など）から見本を選び、使う順に並べて見る
- 構成の型（全景から細部へ、訪問の順、計画の説明）に見本を並べ、カット割り表を再現情報ごとコピーする
- 自分の型を作り、JSONで書き出し・読み込みする（形は `docs/STORYBOARD_JSON.md`）
- 構成を共有リンクで送る（構成のJSONを圧縮して URL の `#story=` に入れる。サーバーには送らない）
- 構成を PowerPoint の絵コンテ（.pptx）で書き出す（`src/story-pptx.ts`。見本の画像は `npm run thumbs:capture` で `public/thumbs/` に作る）
- 場面を書いてAIへの依頼文をコピーし、AIが返した構成を読み込む（依頼文は `src/story-prompt.ts`。見本の一覧は自動で作る）
- 感覚語や用途で、4つの見本帳をまとめて検索する
- 2つの見本を横に並べて、同時に再生して比べる
- 速度・強さ・向きを変えて再生する
- 気に入った見本を保存し、用途別のコレクションに分ける（保存先はこの端末のブラウザ内だけ）
- 各見本の再現情報（CSS、Premiere Pro／After Effects、PowerPoint、建築CG、生成AI向けの指示文）をコピーする

## 使い方ページ

操作方法は、サイト右上の「使い方」（`/guide.html`）にまとめています。

- 内容は `src/guide.ts` の `sections`（項目ごとの説明）と `changelog`（更新履歴）で管理しています。
- 見本の件数や、「強さ」「向き」が効く見本の一覧は、見本帳と共通の `src/data.ts` から自動で反映されます。
- 冒頭の「画面マップ」の画像と番号の位置は、画面の構成を変えたら `npm run guide:capture` で撮り直します（Playwrightが必要。手順は `scripts/capture-guide-map.cjs` の冒頭）。番号の説明文は `src/guide.ts` の `mapItems` にあります。
- 機能を追加・変更したPRでは、使い方ページも同じPRで更新します（PRテンプレートで確認）。

## 見本を追加するとき

1. `src/data.ts` に見本の基本情報（名前、説明、向いている場面、避けたい場面、感覚語）を足す
2. `src/recipes.ts` に同じ番号で再現情報を足す（開発サーバーでは、足りないと警告が出ます）
3. プレビューの画面とCSSを `src/main.ts`・`src/style.css` に足す
4. 「強さ」「向き」が効く場合は `src/data.ts` の一覧に番号を足す（使い方ページにも自動で反映）
5. 当てはまる目的と、カメラ系ならカットの大きさを `src/purposes.ts` に足す
6. 構成の型で使える場合は、合う役割の候補に番号を `src/storyboard.ts` に足す
